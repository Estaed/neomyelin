# Private

Official papers and anything sensitive: identity documents, visas, contracts, banking, tax. Recall
never indexes this folder, so nothing in it reaches a session unless someone opens the file. Give
each note here `visibility: private` in its frontmatter, as this one has, so it stays marked
private wherever it is moved. Keep an index of where each document is rather than a copy of what
it says.

Example sub-folder: `Documents/`
