# Rules

Binding. Each rule says where to arrive and why; how to get there is the assistant's choice. Every
session prints this file whole: keep it under 7,000 bytes (`doctor.py` warns past that). When there
is no room, the weakest rule goes; git keeps it.

A correction from the user becomes a rule here in the same session: the rule in one bold sentence,
then why in italics, quoting the user's own words. The example shows the shape and is not a rule
until the user's own correction writes one:

> - **Answer short and direct**, no filler. *"just show me the result"*
